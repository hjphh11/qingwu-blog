# 设计规范 · 清吾

> 这份文件是**改代码前先看的那一页**。
> 它说明设计 token 怎么定、页面骨架怎么搭、哪些是硬约束。
> 配套:`项目设计.md`(要做什么/参考了什么)、`参考来源与版权.md`(借鉴来源)。

## 1. 三支旋钮(改动前的默认值)

这套站点的「设计读数」是:
**一个温馨二次元的个人博客**,受众是站主自己 + 一小圈同好,气质偏**编集感 + 角色品牌**。

| 旋钮 | 取值 | 说明 |
|---|---|---|
| `DESIGN_VARIANCE` | **6** | 不全对称也不混乱:首页两栏(1fr + 300px)、文章页(1fr + 220px)是刻意的非对等分栏,但每个页面内部保持一条左缘基线 |
| `MOTION_INTENSITY` | **5** | 动效要有,但每一项都要能一句话说清目的(见第 5 节);不堆砌 |
| `VISUAL_DENSITY` | **4** | 卡片之间留得开;一屏不塞多组信息 |

**品牌不动的部分**(再怎么优化都不要改):
爱弥斯暖色、玻璃拟态卡片、笔顺问候、单一暖色主题(不做深浅切换)、导航一行不换行。

## 2. 颜色

### 2.1 原始色板(取自爱弥斯)

| token | 值 | 用途 |
|---|---|---|
| `--color-rose` | `#f6a5b8` | 主色玫瑰粉。**只做大面积色块 / 标签底 / 氛围层**,不做小字颜色(在白底上只有 1.9:1) |
| `--color-crimson` | `#c23a55` | 强调色绯红。文字、实心按钮底色都走它 |
| `--color-cream` | `#fdf6f0` | 页面底色 |
| `--color-amber` | `#e8b04b` | 点睛琥珀金。目前只用在氛围光斑 |
| `--color-brown` | `#8b5a3c` | 暖棕。备用,极少用 |
| `--color-ink` | `#4a3728` | 正文深暖棕 |

> ⚠️ **crimson 为什么是 `#c23a55` 而不是更亮的 `#e0526b`**
> 原值在奶油白上只有 **3.51:1**、白字压在上面只有 **3.76:1**,两个方向都过不了 WCAG AA。
> 压深后:奶油白上 **5.0:1**、白字 **5.1:1**。色相(349°)与饱和度几乎没变,仍是同一支绯红。
> **不要为了「更粉嫩」把它调回去** —— 那会把全站小字和按钮一起拖到不达标。

### 2.2 语义色(写页面时用这些,不要手写透明度)

| token | 值 | 对比度 | 用在哪 |
|---|---|---|---|
| `--color-accent` | `= crimson` | 5.0:1 | 正文级强调文字、链接、hover 变色 |
| `--color-accent-soft` | `#a8324a` | 6.3:1 | ≤12px 的极小字 |
| `--color-muted` | `rgba(74,55,40,.9)` | 5.8:1 | 次要文字:副标、卡片摘要 |
| `--color-subtle` | `rgba(74,55,40,.75)` | 4.85:1 | 三级文字:日期、标签、页脚小字 |
| `--color-hairline` | `rgba(194,58,85,.16)` | — | 分隔线、虚线 |

> 🚫 **禁止**再写 `text-ink/50`、`text-ink/60` 这类透明度写法当正文色。
> `text-ink/60` 只有约 3.6:1。要次要文字就用 `text-muted`,三级用 `text-subtle`。
> 全站对比度可以随时用下面的命令复测(见第 6 节)。

## 3. 字号阶梯

相邻层差 **≥ 1.25 倍**,跨层 **≥ 1.6 倍** —— 目的是让「页面标题 / 区块标题 / 卡片标题」一眼分得开。

| token | 值 | 用在哪 |
|---|---|---|
| `--text-display` | `clamp(2rem, …, 3rem)` → 32–48px | 文章详情大标题 |
| `--text-page` | `clamp(1.75rem, …, 2.125rem)` → 28–34px | 页面标题(`.page-head__title`) |
| `--text-section` | `clamp(1.5rem, …, 1.875rem)` → 24–30px | 区块标题(`.section-head`) |
| `--text-subsection` | `1.5rem` → 24px | 卡内小标题(`.card-head`) |
| `--text-cardtitle` | `1.125rem` → 18px | 列表卡片标题(`.list-card-title`) |
| `--text-label` | `0.8125rem` → 13px | 标签 / 日期 / 元信息 |

字体分工:

- `--font-display` = **ZCOOL XiaoWei**:所有标题、文章正文里的 h2/h3。字距 `0.01em`。
- `--font-hand` = **Ma Shan Zheng**:笔顺问候、页脚那句「欢迎来到清吾的小屋」、音乐馆标题、空态。**只做点缀,不做正文**。
- `--font-body` = 系统中文黑体栈:正文。正文 `1.0625rem / line-height 1.8`,行宽用 `max-w-[68ch]`。

## 4. 布局骨架

### 4.1 一个容器,一条左缘线

```html
<div class="page-shell"> … </div>
```

- `max-width: 1080px`,左右内边距 `clamp(1.25rem, .6rem + 2.2vw, 2.5rem)`,顶部 `clamp(6rem, 5rem + 3vw, 7.5rem)`(给固定导航让位),底部 `5rem`。
- **所有页面都必须用它**。以前 `about` 用 `max-w-3xl`(768)、列表页用 `max-w-4xl`(896)、文章页用 `max-w-5xl`(1024),
  换页时左缘会跳 64–128px —— 这是最容易被一眼看出来的「不讲究」。
- 需要更窄的阅读栏(关于页之类)在它之上加 `max-w-[62rem]` 这种覆盖,但**左右内边距仍由 `.page-shell` 给**。

### 4.2 页面标题区

```html
<header class="page-head">
  <h1 class="page-head__title">文章</h1>
  <p class="page-head__sub">写下的故事，都收在这里 ~</p>
</header>
```

竖条由 `::before` 画,不要在 HTML 里再手写 `<span class="h-6 w-1.5 bg-crimson">`。

### 4.3 间距节奏

- 区块之间:`--space-section` = `3.5rem`(`.page-head` 已自带 `margin-bottom`)。
- 卡片之间:`gap-6`(24px)。
- **卡内间距必须 ≥ 卡间距**:`.list-card-meta`(8px)→ `.list-card-title`(10px)→ `.list-card-desc`(8px)→ `.list-card-foot`(16px)。
  以前是「标题 mt-3 / 摘要 mt-2 / 标签 mt-4」,卡内比卡间还挤,层级是塌的。

### 4.4 断点策略

- `lg`(1024px)才分两栏。**不要用 `md`(768px)** —— 768 时两栏会把正文挤到 440px。
- 列表卡片单列 → 桌面也单列(文章列表就该是一列读下来)。
- 分享页是**瀑布流**(CSS `columns-2`),收藏卡矮、语录卡高,不能用等宽 grid(矮卡那行会被拉到最高卡的高度)。
- 任何两栏都要给正文列加 `min-w-0`,否则长英文串会撑破栅格。

## 5. 动效与微交互

**每一项都必须能一句话说清目的**,否则不加。

| 效果 | 目的 | 实现 |
|---|---|---|
| 笔顺问候 | 第一眼的记忆点 | `hanzi-writer`,9 字依次写出;有「跳过笔顺动画」出口 |
| 副标逐词模糊浮现 | 引导视线从上往下 | Motion `staggerChildren` |
| 爱弥斯随滚动缩小淡出 | 把注意力交还给内容 | `useScroll` + `useTransform`(scale 1→0.6) |
| 滚动揭示 | 内容「到齐了」的节奏 | 全局 IntersectionObserver + `.reveal` |
| 卡片聚光 | 指示「这张卡是可点的」 | `.card-spotlight` + 全局 `pointermove` 写 `--mx/--my` |
| 卡片悬停抬升 | 同上 | `.card-lift`(统一类) |
| 按钮涟漪 | 点击有物理反馈 | `.btn-ripple` + 全局委托 |
| 导航胶囊弹簧滑动 | 说明「位置变了」 | Motion `animate` + `spring` |
| 语录翻卡 | 揭示出处 | 纯 CSS `preserve-3d` |
| 氛围光斑 / 樱花 | 营造温馨基调 | CSS 渐变 + canvas |

**硬约束:**

1. **降低动效一律关掉。** `.card-lift` 的位移只在 `@media (hover:hover) and (prefers-reduced-motion:no-preference)` 里生效;
   `global.css` 末尾还有一层 `prefers-reduced-motion: reduce` 兜底,把 Tailwind 的 `hover:-translate-y-*` 也压平。
   新加动效时**不要**直接写 `hover:-translate-y-1`。
2. **切到后台要停。** `Layout.astro` 在 `document.hidden` 时给 `<html>` 加 `.qhidden`,CSS 里 pause 所有持续动画;
   樱花 canvas 和 `BackgroundDecor` 也会在 `visibilitychange` 时 `cancelAnimationFrame`。
   新的持续动画要挂上 `.qhidden` 规则。
3. **触屏没有 hover。** 需要反馈的地方用 `@media (hover:none) { :active { transform: scale(.985) } }`,别指望 hover。
4. **焦点必须可见。** 全站 `:focus-visible` 是 2px 品红描边 + 3px offset。**不要在 `:focus-visible` 里设 `border-radius`**
   —— 那会把胶囊按钮的圆角在聚焦瞬间压成 6px。
5. **可点区域 ≥ 44px 高。** 页脚链接、筛选芯片、翻卡这类都测过。
6. 用类名(`.is-active` / `aria-pressed`)表达选中态,**不要**用 `classList.add('bg-rose/70')` 这种拼 Tailwind 类名的写法
   (斜杠会被当普通字符,而且初始态没有高亮)。

## 6. 改完之后怎么验

```bash
npm run check     # 类型:必须 0 errors
npm run build     # 构建:必须通过
```

另外三个自查项(改完颜色/字号/布局务必跑一遍):

1. **对比度** —— 全站所有文字实测 ≥ 4.5:1(大字号 ≥ 3:1)。
   注意要**按 alpha 合成真实底色**算,不能只看 `color` —— 玻璃卡是半透明的。
2. **横向溢出** —— 1440 / 768 / 390 三个宽度下 `documentElement.scrollWidth` 必须等于 `innerWidth`。
3. **可点区域** —— 390 宽度下不允许出现高度 < 32px 的链接/按钮。

> 开发时 Astro 的 dev toolbar 会浮在页面右下角(深色胶囊),它是开发态产物,**不是**站上的组件。
> 用无头浏览器截图自测时它会出现在图里,别当成 bug 去修。

## 7. 图片

| 文件 | 尺寸 | 用在哪 |
|---|---|---|
| `images/avatar.webp` / `.jpg` | 256² | 导航(32px)、关于页(80px)。**webp 16KB,原 jpg 734KB,所以一律走 `<picture>`** |
| `images/emis/full.webp` / `.png` | 2658×4096 | 首页 Hero。webp 391KB / png 3.7MB |
| `images/emis/portrait.webp` / `.png` | 360×497 | 关于页爱弥斯(180px)。webp 70KB / png 784KB |

新增图片时:

- 显示尺寸 `N` px 的位图,准备 `2N` 的源就够了,**不要**直接塞原图。
- 一律提供 webp,用 `<picture><source srcset=… type="image/webp"><img …></picture>`,保留原格式做兜底。
- Astro 模板里 `<source>` 的属性名是 **小写 `srcset`**(不是 JSX 的 `srcSet`),写错 `astro check` 会报错。
- 非首屏图片加 `loading="lazy"` + `decoding="async"`。
