## 2. 版权约定（长期有效，务必遵守）

1. **无论「照搬」还是「借鉴思路重写」，一律保留 MotionVault 的 MIT 版权声明**。
   - 照搬整段代码：在原文件头部或项目统一注明来源 + MIT。
   - 借鉴思路自行实现：至少在本文件「借用追踪表」里登记，并在相关代码旁加一行来源注释（`// from MotionVault (MIT) — <效果名>`）。
2. **每个效果按实际情况二选一，并明确标注**：
   - `照搬`：直接/基本照搬其实现，仅在配色、字体、尺寸上按本站主题调整。
   - `借鉴`：只取其思路/参数/手法，用本站自己（贴爱弥斯暖色）的代码重写实现。
3. **不改动设计方向**：Mv 里大量效果是**冷灰白色系**（zinc/极简白）。接入本站时必须**重着色为爱弥斯暖色（玫瑰粉/绯红/奶油白/琥珀金/暖棕）**，不要照搬冷色调。
4. **不搬运静态素材**：不拷贝其预览 PNG/GIF、logo、`social-preview.png` 等展示素材。
5. **动效克制**：遵守项目「克制的、有目的的动效」原则，并非 Mv 里每个效果都要；接入需评估是否契合「温馨二次元」。
