## 后台（已移除，仅存档）

## 根目录结构

```
src/           站点源码（Astro + React + Tailwind）
  pages/       路由（首页 / 文章 / 音乐 / 友链 / 分享 / 项目 / 关于 / 更新日志）
  components/  组件
  styles/      分层样式：tokens → fonts → base → layout → ui → prose → effects → motion
  data/        内容数据（文章以外的：友链、音乐、项目、关于、分享、分类、更新日志）
  lib/         运行时逻辑（音乐 store、图标、校验）
public/        静态资源（字体子集、图片、歌词、笔顺 JSON）
scripts/       构建辅助与验收脚本（check:home / check:pages / check:final 等）
worker/        Cloudflare Worker（D1 接口，无页面）
docs/          本目录：设计与决策记录，不参与构建
.workbuddy/    项目记忆与工作日志
```
